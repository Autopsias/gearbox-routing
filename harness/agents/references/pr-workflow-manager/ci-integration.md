# CI Check Integration Patterns

## Quality Gate Integration

### Standard Mode (default, no --fast flag)

**For commits in standard mode:**
```bash
# Standard mode: use git commit directly (hooks will run)
# Pre-commit: ~5s (formatting only)
# Pre-push: ~15s (parallel lint + type check)
git add -A
git commit -m "$(cat <<'EOF'
<auto-generated message>

Generated with [Claude Code](https://claude.ai/claude-code)

Co-Authored-By: Claude Opus 4.5 <noreply@anthropic.com>
EOF
)"
git push
```

### Fast Mode (--fast flag present)

**For commits in fast mode:**
```bash
# Fast mode: skip all hooks
git add -A
git commit --no-verify -m "<message>"
git push --no-verify
```

### Delegate to Specialist Orchestrators (only when needed)

**When CI fails (not in --fast mode):**
```bash
SlashCommand(command="/ci_orchestrate --check-actions")
```

**When tests fail (not in --fast mode):**
```bash
SlashCommand(command="/test_orchestrate --run-first")
```

### Optional Parallel Validation

If user explicitly asks for quality check, spawn parallel validators:

```python
# Use Task tool to spawn validators
validators = [
    ('security-scanner', 'Security scan'),
    ('linting-fixer', 'Code quality'),
    ('type-error-fixer', 'Type checking')
]

# Only if available and user requested
for agent_type, description in validators:
    Task(subagent_type=agent_type, description=description, ...)
```

## Validate (Quality Gates)

```bash
# Check CI status
CI_STATUS=$(gh pr checks --json state --jq '.[].state')

# Run optional quality checks if tools available
if command -v pytest &> /dev/null; then
    echo "Running tests..."
    pytest
fi

# Check coverage if available
if command -v pytest &> /dev/null && pip list | grep -q coverage; then
    pytest --cov
fi

# Spawn quality agents if needed
if [[ "$CI_STATUS" == *"failure"* ]]; then
    SlashCommand(command="/ci_orchestrate --fix-all")
fi
```

## Check Status (includes merge conflict warning)

```bash
# Show PR info for current branch with merge state
PR_DATA=$(gh pr view --json number,title,state,statusCheckRollup,reviewDecision,mergeStateStatus 2>/dev/null)

if [[ -n "$PR_DATA" ]]; then
    echo "## PR Status"
    echo ""
    echo "$PR_DATA" | jq '.'
    echo ""

    # Check merge state and warn if dirty
    MERGE_STATE=$(echo "$PR_DATA" | jq -r '.mergeStateStatus')
    PR_NUM=$(echo "$PR_DATA" | jq -r '.number')

    echo "### Summary"
    echo "- Checks: $(gh pr checks 2>/dev/null | head -5)"
    echo "- Reviews: $(echo "$PR_DATA" | jq -r '.reviewDecision // "NONE"')"
    echo "- Merge State: $MERGE_STATE"
    echo ""

    if [[ "$MERGE_STATE" == "DIRTY" ]]; then
        echo "PR #$PR_NUM has MERGE CONFLICTS"
        echo ""
        echo "GitHub Actions limitation:"
        echo "- E2E, UAT, Benchmark jobs will NOT run"
        echo "- Only Lint + Unit tests run via push event"
        echo ""
        echo "Fix: /pr sync"
    elif [[ "$MERGE_STATE" == "CLEAN" ]]; then
        echo "No merge conflicts - full CI coverage enabled"
    fi
else
    echo "No PR found for current branch"
fi
```

## TASKLIST INTEGRATION

**Purpose:** Track PR workflow operations with task visibility. **Skip TaskList for --fast mode** to maintain speed.

### OPERATION-SPECIFIC TASK CHAINS

#### For "create" operation:
```
IF NOT --fast mode:
  TaskCreate(subject="Check branch status", description="Verify branch and commits", activeForm="Checking branch")
  TaskCreate(subject="Run pre-push validation", description="Execute quality gates", activeForm="Validating") -> blockedBy: [1]
  TaskCreate(subject="Push to remote", description="Push commits to origin", activeForm="Pushing") -> blockedBy: [2]
  TaskCreate(subject="Create PR on GitHub", description="Create pull request with gh CLI", activeForm="Creating PR") -> blockedBy: [3]
END IF
```

#### For "update" operation (default):
```
IF NOT --fast mode:
  TaskCreate(subject="Check merge state", description="Verify no merge conflicts", activeForm="Checking merge state")
  TaskCreate(subject="Stage and commit", description="Stage changes and create commit", activeForm="Committing") -> blockedBy: [1]
  TaskCreate(subject="Push to remote", description="Push commits (hooks will run)", activeForm="Pushing") -> blockedBy: [2]
END IF
```

#### For "validate" operation:
```
IF NOT --fast mode:
  TaskCreate(subject="Check CI status", description="Query GitHub Actions status", activeForm="Checking CI")
  TaskCreate(subject="Analyze failures", description="Parse CI failure logs", activeForm="Analyzing") -> blockedBy: [1]
  TaskCreate(subject="Fix issues", description="Spawn specialist agents for fixes", activeForm="Fixing issues") -> blockedBy: [2]
  TaskCreate(subject="Re-push", description="Push fixes and verify CI", activeForm="Re-pushing") -> blockedBy: [3]
END IF
```

#### For "merge" operation:
```
IF NOT --fast mode:
  TaskCreate(subject="Verify all checks pass", description="Confirm CI green and reviews approved", activeForm="Verifying checks")
  TaskCreate(subject="Merge PR", description="Merge with appropriate strategy", activeForm="Merging") -> blockedBy: [1]
  TaskCreate(subject="Post-merge cleanup", description="Checkout base, pull, cleanup branches", activeForm="Cleaning up") -> blockedBy: [2]
END IF
```

#### For "sync" operation:
```
IF NOT --fast mode:
  TaskCreate(subject="Fetch base branch", description="Fetch latest from origin", activeForm="Fetching")
  TaskCreate(subject="Merge base into current", description="Resolve conflicts if any", activeForm="Merging") -> blockedBy: [1]
  TaskCreate(subject="Push merged branch", description="Push to enable full CI", activeForm="Pushing") -> blockedBy: [2]
  TaskCreate(subject="Verify merge state clean", description="Confirm PR no longer DIRTY", activeForm="Verifying") -> blockedBy: [3]
END IF
```

### FAST MODE BYPASS

```
IF --fast mode:
  # Skip all TaskList operations for maximum speed
  # Direct git commands only: git add -A && git commit --no-verify && git push --no-verify
  Output: "Fast mode: Skipping task tracking for speed"
END IF
```

### TASK STATUS UPDATES

```
# When starting each operation step:
TaskUpdate(taskId=step_task_id, status="in_progress")

# When completing each step:
TaskUpdate(taskId=step_task_id, status="completed", metadata={"result": "success"})

# When step fails:
TaskUpdate(taskId=step_task_id, status="completed", metadata={"result": "failed", "error": "..."})
```

### CONFLICT WARNING METADATA

When merge conflicts detected:
```
TaskUpdate(taskId=check_task_id, metadata={
  "merge_state": "DIRTY",
  "pr_number": {num},
  "ci_limitation": "E2E/UAT/Benchmark jobs will not run",
  "recommendation": "/pr sync"
})
```
